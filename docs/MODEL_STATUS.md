# Model and artifact status

| Component | Included in archive | Status |
|---|---:|---|
| YOLO face detection code | Yes | Configured to load YOLOv8n-face; checkpoint is fetched by `scripts/download_face_model.py` |
| MediaPipe FaceMesh | Yes | Runtime dependency; installed through `requirements.txt` |
| Five-class mask classifier architecture | Yes | MobileNetV3-Large classifier with five output classes |
| Five-class trained classifier weights | **No** | Must be produced with `train.py` using the five labelled folders |
| Image-quality module | Yes | Implemented; occlusion value is a landmark-availability proxy |
| Uncertainty estimation | Yes | Implemented with entropy, confidence and quality |
| Temporal tracker and 5-second alert | Yes | Implemented with IoU association and CSV logging |
| Text explanation / Grad-CAM | Yes | Implemented; Grad-CAM is optional for speed |
| Training and evaluation reports | Yes | Generated by the actual training run; no fabricated values are bundled |

The five-class checkpoint is intentionally not fabricated. A random head or a checkpoint trained on unrelated synthetic placeholders would not be a well-trained model and would give misleading results.
